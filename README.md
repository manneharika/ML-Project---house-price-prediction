 Project Title: House Price Prediction using Regression Techniques
🧾 Project Description:

This project aims to build a machine learning model to predict housing prices using various features such as location, number of bedrooms, living area, and renovation status. The dataset used for this project is "House Price India", and the workflow includes data preprocessing, exploratory data analysis (EDA), feature engineering, model training using multiple regression algorithms, and model evaluation.
✅ Key Features and Workflow:

    Dataset Loading and Cleaning:

        Imported a housing dataset with features like sale price, year built, renovation year, square footage, etc.

        Cleaned null values and transformed date formats.

    Feature Engineering:

        Calculated derived features such as:

            Age of the house.

            Whether the house was renovated or not.

            House price per square foot.

        Applied log transformation to price for normalization.

    Exploratory Data Analysis (EDA):

        Visualized distributions using histograms, box plots, and heatmaps.

        Analyzed correlation between features and target variable.

    Model Building:

        Implemented and trained multiple regression models:

            Linear Regression

            Lasso Regression

            Ridge Regression

        Evaluated model performance using R² score and Mean Squared Error.

    Conclusion:

        Identified the most impactful features on house pricing.

        Linear Regression gave a solid baseline for prediction accuracy.
